# B03 — Conical incidence

Compare cross-polarized complex diffraction amplitudes for off-axis illumination of the B01 structure.

The geometry and scan points are defined in [case.yaml](case.yaml). Lengths and vacuum wavelengths use nanometers, and angles use degrees.

```powershell
rcwa-cv run B/B03 --profile quick
rcwa-cv converge B/B03
```
